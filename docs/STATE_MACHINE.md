# 三花猫桌宠状态机与精灵替换指南

本项目采用一个轻量的**事件驱动有限状态机**。渲染器只保存当前动作、当前帧与定时回退动作；鼠标、系统菜单、屏幕边界和静置计时器分别作为状态转换触发源。窗口控制由主进程处理，渲染器则只能经由预加载接口请求有限的移动、掉落和菜单操作；这种“窄接口”模式符合 Electron 对隔离上下文与逐项暴露 IPC API 的安全建议。[1]

> 基础像素美术由 `tools/generate_sprites.py` 代码生成，定位为**可运行的占位像素素材**。后续美术替换时，应保持 `assets/sprite-map.json` 的动作名称、每帧尺寸（64×64）与帧序列不变；也可以在替换图集后同步调整该 JSON 的帧索引。

## 状态转换概览

```text
启动 → idle（默认安静陪伴）
  │
  └─ 关闭“安静陪伴模式” → {walk / sit / groom_paw / groom_coat / scratch_ear / tail_swish / yawn / stretch / sleep}
  │       │
  │       ├─ 鼠标悬停 → look → 鼠标离开 → idle
  │       ├─ 单击 → rub + “喵~” → idle
  │       ├─ 双击 → jump + 爱心 → idle
  │       ├─ 拖拽中 → drag → 松手 → 掉落到工作区底面 → idle
  │       ├─ 长按 ≥ 780 ms → belly → 松开 → idle
  │       ├─ 右键投喂 → eat → sit / idle
  │       ├─ 毛线球 → yarn → pounce → idle
  │       └─ 静置 ≥ 5 分钟 → attention → idle
  │
  └─ walk / run → 屏幕工作区边缘 → sit → 掉头 → walk
```

## 自动行为规则

| 状态或事件 | 触发条件 | 动作与持续时间 | 后续状态 |
| --- | --- | --- | --- |
| `idle` | 启动、任意短动作结束 | 站立呼吸；6 帧循环 | **默认安静待机**；关闭“安静陪伴模式”后才会进入低频随机行为或 `walk` |
| `walk` | 关闭“安静陪伴模式”后，启动约 2.2 秒或随机动作结束 | 以约 3 px / 130 ms 水平移动；6 帧循环 | 到边缘时 `sit`，否则持续行走 |
| `run` | 预留给高速移动策略；可由扩展逻辑触发 | 以约 7 px / 75 ms 移动；6 帧循环 | `walk` 或 `idle` |
| 随机日常行为 | **仅关闭安静陪伴模式时**；近 5 分钟内有用户操作，且猫咪没有被拖拽或占用 | 从坐下、舔爪、理毛、挠耳、甩尾、哈欠、伸展、睡觉中随机抽取 | `idle`，再以概率恢复 `walk` |
| `attention` | **仅关闭安静陪伴模式时**，连续 5 分钟无任何鼠标/菜单操作 | 7.2 秒抬头张望、显示“喵……看看我嘛。” | `idle` |
| 边缘休息 | 行走到当前显示器工作区左右边缘 | 坐下 1.7 秒、调转方向 | `walk` |

## 互动规则

| 用户行为 | 触发阈值 | 状态与视觉反馈 | 音效与窗口行为 |
| --- | --- | --- | --- |
| 单击 | 两次点击间隔大于 290 ms | `rub`，文字气泡“喵~” | 合成喵叫；恢复后继续散步 |
| 双击 | 两次点击间隔不超过 290 ms | `jump`，四颗爱心向上飘出 | 合成喵叫；恢复后继续散步 |
| 拖拽 | 指针移动总距离超过 6 px | `drag`，四肢悬空 | 窗口随指针移动；松手后进入下落模拟 |
| 快速拖拽 | 当前实现将其呈现为 `drag`；可在 `pointermove` 扩展为 `run` | 挣扎帧显示 | 不影响松手后的下落 |
| 松手下落 | 拖拽释放 | `drag` 后的速度递增式下落 | 落到当前显示器工作区底部，始终停在任务栏上方 |
| 长按 | 按住至少 780 ms，且未进入拖拽 | `belly`，翻肚皮卖萌 | 气泡“呼噜……”与合成喵叫 |
| 眼球跟随鼠标 | `idle`、`look`、`attention`、`tail_swish`、`walk` 或 `run` 动作期间 | 每约 80 ms 读取一次全屏鼠标坐标；两个瞳孔以平滑、最多 1 个源像素的方向位移追踪鼠标 | 不改变当前动画状态；被拖拽、睡眠或理毛时归中 |
| 鼠标悬停 | 指针进入猫咪窗口 | `look`，眼球持续跟随与尾巴上扬 | 离开后回到 `idle` |
| 投喂小鱼干 | 右键菜单命令 | `eat`，鱼干像素道具靠近猫咪 | 气泡“小鱼干！” |
| 毛线球 | 右键菜单命令 | `yarn` → `pounce` | 气泡“毛线球！” |

| --- | ---: | ---: | --- | --- |

| `sleep` | 12–17 | 6 | 是 | 趴睡呼吸与睡眠符号 |
| `yawn` | 18–21 | 4 | 否 | 随机打哈欠 |
| `stretch` | 22–27 | 6 | 否 | 随机伸懒腰 |

## 替换美术的操作约定

后续若委托像素画师，建议直接提供 `assets/sprite-map.json` 与本文件。画师应依照现有帧顺序绘制 64×64 PNG 帧，在一个**横向 8 列**的透明背景 Sprite Sheet 中拼合，之后覆写 `assets/calico-sprites.png`。如果新增动作，需同步新增 `sprite-map.json` 的动画条目，并在 `renderer.js` 的 `setAction()` 调用点绑定新状态。

建议保留外轮廓的深紫黑色、白底与橘黑不规则块的三花辨识点，并固定**画面左眼为金黄色、画面右眼为蓝色**的异瞳特征。让动作关键姿势分别集中在第 1、3、6 帧；这样即使在 3 倍整数缩放下，猫咪的眼神、尾巴和爪子也能清晰可读。
